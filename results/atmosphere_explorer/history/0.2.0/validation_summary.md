# 霧と塵の比較ページの検証

64条件の全分光データを確認し、有限・非負、消散係数の鉛直積分、分光値からXYZへの変換、画面の埋込値との一致を確認しました。
実装の35テストは合格しています。これは数値収束の合格を意味しません。

角度分解能（14→26点）の変更による、サンプル視線の最大輝度差：

|条件|太陽高度0°|−6°|−12°|−18°|
|---|---:|---:|---:|---:|
|都会|14.7%|20.2%|458.1%|25,226.2%|
|田舎|9.3%|39.4%|854.4%|93,485.9%|
|高湿度|62.2%|107.7%|509.2%|26,460.8%|
|低湿度|17.8%|30.4%|699.5%|52,944.5%|

いずれも比較の目安（輝度差5%・xy距離0.005）を満たさず、角度分解能の依存性が残っています。深い薄明の非常に小さい太陽成分では、相対差が大きくなります。

高湿度の初期条件では、波長20→10 nm、反復回数、Mie係数数は比較の目安を満たしました。鉛直・水平格子の変更は未達でした。全条件の精度・観測との一致の保証ではありません。

画面操作では、4種類の切替、霧・塵の変更、朝夕切替、見る方向、露出、同じ霧・塵での比較、初期値復帰を確認しました。
ブラウザーから保存したJSONと390行のCSVを検査し、設定値・輝度・RGBが保存済み分光データと一致しました。verification/ に検査用ダウンロードを保存しています。
