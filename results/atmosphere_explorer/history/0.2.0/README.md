# 霧・塵・湿度の比較（ライブラリ0.2.0 / モデル2.1）

`results/atmosphere_explorer/index.html` はネット接続なしで動きます。都会・田舎・湿度が高い・湿度が低いの4種類を用意し、それぞれに乾燥微粒子AOD `[0, 0.03, 0.10, 0.30]` と霧AOD `[0, 0.05, 0.20, 0.80]` の全組合せを計算しました。太陽高度は +5,+2,0,−2,−4,−6,−9,−12,−15,−18°、相対方位は0,90,180°、高度角は0〜90°の13点です。

## 4種類の初期条件

| 種類 | 微粒子層RH | 乾燥AOD | 霧AOD | κ | 乾燥粒子の屈折率 n − ik | 微粒子のスケール高度 |
|---|---:|---:|---:|---:|---|---:|
| 都会 | 60% | 0.30 | 0 | 0.20 | 1.50 − 0.010i | 1200 m |
| 田舎 | 60% | 0.03 | 0 | 0.30 | 1.45 − 0.003i | 1500 m |
| 湿度が高い | 90% | 0.10 | 0.20 | 0.30 | 1.45 − 0.005i | 1500 m |
| 湿度が低い | 30% | 0.10 | 0 | 0.30 | 1.45 − 0.005i | 1500 m |

特定の都市・地域の観測値ではなく、比較のために設定した仮想大気です。都会・田舎は粒子の吸収特性も異なります。湿度の2条件は乾燥粒子特性を共通にしています。高湿度の初期条件では霧も加えているため、RHだけを比較するには「現在の塵・霧の量に揃えて比較」を選んでください。

## 追加した物理過程

微粒子の乾燥中央値半径は100 nm、幾何標準偏差は1.6です。RHを割合（0.9 = 90%）で与え、κパラメータ化による `GF³ = 1 + κ RH/(1−RH)` を使います。対数正規分布の半径をGF倍し、乾燥粒子と水の体積加重平均で複素屈折率を求めます。乾燥AODから粒子数を決め、湿った550 nm AODは `乾燥AOD × 湿った消散断面積 / 乾燥消散断面積` で計算します。断面積・波長特性・位相関数はMie計算です。単純にAODをGF²倍する近似ではありません。

この近似はKelvin項、潮解・風解の履歴、粒径ごとのκの違いを省略します。乾燥中央値半径40 nm以上、RH≤95%の範囲に制限しています。RHは微粒子層に一様に適用し、US76の気体温度・密度や屈折率の水蒸気項は変更しません。湿度分布全体を解くモデルではありません。

霧は独立した水滴粒子群です。中央値半径5 µm、幾何標準偏差1.3、水の可視域一定屈折率1.333 − 10⁻⁹i、鉛直消散係数 `exp(−z/200 m)` を仮定します。地表から100 kmまでの数値積分が指定霧AODになるよう正規化し、水滴数を変えます。水蒸気の凝結や霧の発生・消散の時間変化は計算しません。霧とRHは独立の入力なので、低湿度で霧を増やす組合せは比較用の仮想条件になります。

球形・単一モード微粒子の近似であり、粗大な不規則形状の砂塵、煤の集合体、粒子混合状態の詳細は表現しません。

## 数値設定と表示

`fog_preview` プリセットは近地表大気50 m／散乱源100 m、角度14点、水平21列、20 nmスペクトル幅、256 Legendre係数、Delta-M次数16です。水滴の強い前方散乱に対する近似を有効にし、細かい低層格子で霧の鉛直分布を表現します。名称は精度の保証ではなく、全条件の数値収束・観測との一致は未確認です。実施した代表条件の感度確認は `results/atmosphere_explorer/numerical_sensitivity.json` に記録します。

スライダーは実際に計算した離散値だけを選びます。霧・塵・太陽高度の計算点間を色や分光値で補間しません。空の縦断面のグラデーションだけ、13高度のXYZを補間します。波長は380〜780 nmの20 nm幅ビンで太陽スペクトルとCIE等色関数を積分し、輸送はビン中心で評価します。

「色だけ」は各高度の最大線形RGBを1に正規化します。輝度の情報は含みません。「共通の露出」はXYZを100で割り、2^EVを掛けてsRGBを表示します。明るい領域・sRGBの色域外はクリップされるため、輝度の数値と併せて確認してください。CSVのRGBは「色だけ」の正規化値で、画面の露出設定に依存しません。

朝は太陽高度が上がる順、夕は下がる順で同じ静的な大気計算を使います。朝夕の気象差、雲、地形、都市光害、月・星・夜光、暗所での色覚は含みません。

## 保存したファイル

- `index.html`：4種類を切り替える比較ページ。
- `urban/`, `rural/`, `humid/`, `dry/`：それぞれを初期選択したページと、初期条件の通常出力（sky.nc、CSV、baseline.html）。
- `calculations/<種類>/dust<i>_fog<j>.nc`：64条件それぞれの全分光計算、光学厚さ・消散係数・XYZ・再現設定・入力ハッシュ。
- `data.json`：オフライン画面のデータ。HTMLにも同じ値を埋め込みます。
- `manifest.json`：全ケースの設定、ソース・入力・結果のSHA-256。
- `numerical_sensitivity.json`：代表条件で格子などを変えた数値感度の記録。

再生成は `python -m akutou_sky explore --output results/atmosphere_explorer --cache-dir model_cache --offline --resume`。入力・コード・設定・軸が一致する完成済みケースは再利用します。任意の霧・塵・RHの値は既存の `simulate` コマンドまたはPython APIで計算できます。

```python
from akutou_sky import ModelConfig, simulate, export_results

config = ModelConfig.from_preset('fog_preview', aod550=0.08,
    fog_aod550=0.12, relative_humidity=0.85, hygroscopicity_kappa=0.30)
sky = simulate([-2, 0, 6, 12], config=config,
    elevations=[0, 1, 5, 15, 30, 60, 90], azimuths=[0, 90, 180],
    cache_dir='model_cache', allow_download=False)
export_results(sky, 'results/custom_fog')
```
