# モデルと根拠（akutou-sky 0.4 / モデル3.0）

あくとうで再現したい「理想的な朝焼け・夕焼け・薄明」を、球面大気の放射伝達計算で求めるモデルの説明です。精度の検証結果は [精度検証.md](精度検証.md) にまとめています。

## 何を計算しているか

太陽光が大気で散乱されて観測者に届く**分光放射輝度** `L(λ)` [W m⁻² sr⁻¹ nm⁻¹] を、太陽の伏角・見る方向ごとに計算します。そこから色（CIE xy）と輝度 `Y` [cd/m²] を求め、RevC の4つの高度帯で平均して LED の駆動値にします。

```text
Scene（大気の中身）＋ Numerics（数値の細かさ）
   └─ solver.render ── 分光放射輝度 L(λ)
        └─ color ─────── XYZ・xy・輝度、4高度帯の平均
             └─ led ──── ESP32 用 PWM デューティ表（Cヘッダ）
```

角度はすべて幾何学的な角度（度）です。

| 記号 | 意味 |
|---|---|
| 伏角 d | 太陽中心が地平線の下にある角度。正なら地平線の下（夕方は増え、朝は減る） |
| 高度 h | 見る方向の地平線からの角度（0〜90°） |
| 方位 | 太陽からの相対方位。0°が太陽側、180°が反対側 |

大気は時間変化しないと仮定するので、同じ伏角なら朝と夕で同じ結果です。

## 物理モデル

| 項目 | 扱い | 根拠・制約 |
|---|---|---|
| 幾何 | 半径6371 kmの球面、上端100 km。太陽面を含む2次元の大気（地球の影を含む） | 水平方向の温度・粒子分布は一様 |
| 気体 | US Standard Atmosphere 1976 の温度・気圧 | 観測日の気象ではない |
| 分子散乱 | Rayleigh散乱 | SASKTRAN2 の実装 |
| オゾン | FASCODE標準の鉛直形状を300 DUに規格化、DBM吸収断面積 | Chappuis帯の吸収が薄明の天頂の青さを生む（Hulburt 1953） |
| 対流圏エアロゾル | 対数正規粒径分布（中央値半径100 nm、幾何標準偏差1.6）、屈折率 1.45−0.005i のMie散乱。指数関数の鉛直分布（スケール高度1.5 km）、量は550 nmの乾燥AODで指定 | 球形・単一モード |
| 吸湿成長 | `GF³ = 1 + κ RH/(1−RH)` で粒径を拡大、体積比で水と屈折率を混合、粒子数を保つ | Petters & Kreidenweis (2007)。Kelvin項・履歴は省略。RH ≤ 95% |
| 成層圏の背景エアロゾル | 硫酸液滴（半径80 nm、1.43−10⁻⁸i）、中心20 km・幅4 kmのガウス分布、AOD 0.005（既定） | 薄明の「紫の光」に効く。火山噴火後は大きく変わる |
| 霧 | 独立した水滴層（中央値半径5 µm、幾何標準偏差1.3、水の屈折率 1.333）、スケール高度200 m | 凝結や霧の発生は解かない |
| 地表 | Lambert反射、反射率0.1 | 波長によらない |
| 太陽光 | TSIS-1 HSRS 太陽スペクトル、1 AU | 太陽円盤そのもの（直達光）は空の輝度に含めない |
| 屈折 | **既定では入れない**（`solar_refraction=False`） | SASKTRAN2 は太陽光の経路を曲げるが、屈折による光束の広がり（減光）を入れないため、薄明の空を約2倍明るく見積もる。屈折なしの方が実測照度と一致する（[精度検証.md](精度検証.md)）。視線と散乱光の屈折は Geometry2D が未対応 |
| 偏光 | スカラー計算に、粗い格子で求めた「偏光あり−なし」の差を加える（既定）。霧なしなら `num_stokes=3` で I/Q/U を直接解くこともできる | 偏光を無視すると薄明の輝度が最大13%、色度が0.015ずれる |
| 波長 | 380〜780 nm、既定10 nm幅 | 太陽スペクトルは区間平均、等色関数は区間積分 |

## 数値解法

SASKTRAN2 の Geometry2D（球面・2次元）逐次散乱法（successive orders）を使います。放射輝度を成分に分けて、それぞれに合った格子で計算します。

```text
L = L_1回散乱（細かい高度格子）
  + L_多重散乱（散乱源の格子で解いた場 − 同じ格子での1回散乱）
  + ΔL_偏光（粗い格子での I/Q/U 計算 − スカラー計算）
```

- **1回散乱**は地球の影の境界をまたぐため高度格子に敏感です。0–1 km を25 m、1–10 km を125 m、10–30 km を250 m、30–100 km を500 m 刻みで積分します。
- **多重散乱**は、散乱源の高度を下層から 100/2000/4000/8000 m 刻み、大気の高度格子を 50/500/2000/4000 m 刻み、太陽面内の水平方向を観測者の位置±3°は0.5°刻み（外側は間隔を2倍ずつ広げて±45°まで）で解きます。
- 精度を最も左右するのは**散乱光が入ってくる方向の積分点数**（Lebedev 求積）です。既定（`final`）は入射302方向、散乱源の標本は出射50方向です。深い薄明では入射点数を増やすほど結果が変わるため、ここに計算資源を集中させています（[精度検証.md](精度検証.md)）。
- **スカラー計算**では、前方に鋭い散乱（特に霧）を整合的な Delta-M 打切り（Wiscombe 1977。次数は霧なし16・霧あり32）で扱い、1回散乱は完全な位相関数で TMS 補正（Nakajima & Tanaka 1988）します。
- **偏光補正**は、太陽光の1回散乱はスカラーで厳密なので多重散乱にだけ効きます。同じ粗い格子でベクトルとスカラーを解き、その差を加えます（格子の誤差が打ち消し合う）。霧があるときも同じ方法です。
- メモリを抑えるため、伏角をいくつかのグループに分けて多重散乱を解きます（約10 GB 以内）。

数値設定は `Numerics` にまとまっています。

| プリセット | 用途 | 入射/出射方向 | 波長幅 | 目安の時間 |
|---|---|---|---|---|
| `preview` | 動作確認 | 110 / 26 | 20 nm | 数十秒 |
| `compare` | 比較ページ（64条件） | 302 / 50 | 20 nm | 1条件3〜6分（霧あり約13分）、全体で約10時間 |
| `final` | LED 表・精度検証（既定） | 302 / 50 | 10 nm | 晴天で約7分 |

## 色と輝度

CIE 1931 2°等色関数で

```text
X = 683 Σ L(λᵢ) ∫ x̄ dλ,  Y = 683 Σ L(λᵢ) ∫ ȳ dλ [cd/m²],  Z = 683 Σ L(λᵢ) ∫ z̄ dλ
x = X/(X+Y+Z),  y = Y/(X+Y+Z)
```

RevCの4高度帯（0–5°、5–15°、15–35°、35–60°）の値は、XYZ を `cos h` で重み付けした立体角平均です。RGBではなく光の量（XYZ）で平均します。

## LED への変換（`akutou-sky led`）

1. 指定方位（既定は太陽側）の4高度帯の XYZ を伏角ごとに求める
2. 輝度を圧縮：`Y_LED = (Y / Y_ref)^p`（既定 p = 0.5、`Y_ref` は表中で最も明るい帯）。実際の薄明は約6桁明るさが変わり、ドームのLEDでそのまま出すことはできないため。p = 1 なら比例
3. 色度 xy は保ったまま、LED原色の3×3行列で R・G・B のデューティを解く
4. LEDで出せない鮮やかな色は、同じ輝度のまま LED の白の方向へ彩度を落とす
5. PWM のデューティは光量に比例するので、ガンマ補正はしない。12 bit の1段（1/4095）未満は0

LED原色は既定では sRGB の値です。分光放射計などで各チャネルの xy と最大輝度を測ったら、[led_primaries.example.json](../led_primaries.example.json) の形式で `--primaries` に渡してください。帯ごとに違う LED なら `"bands": [...]` に4組書けます。ドームの反射や配光の重なりは含まれないので、最終的には実機で見え方を確認して `--exponent` を調整します。

## 含まないもの

太陽円盤の直達光、夜光・星・月・街明かり（伏角12°付近から先は背景光が無視できなくなる）、雲、地形、水平方向の大気のむら、視線と散乱光の屈折、可視域の O₂・H₂O・NO₂ の細い吸収帯、暗所での人間の色覚の変化。
