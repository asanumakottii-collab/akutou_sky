# モデルと根拠（akutou-sky 0.5 / モデル3.1）

あくとうで再現したい「理想的な朝焼け・夕焼け・薄明」を、球面大気の放射伝達計算で求めるモデルの説明です。精度の検証結果は [精度検証.md](精度検証.md) にまとめています。

## 何を計算しているか

太陽光が大気で散乱されて観測者に届く**分光放射輝度** `L(λ)` [W m⁻² sr⁻¹ nm⁻¹] を、太陽の伏角・見る方向ごとに計算します。そこから色（CIE xy）と輝度 `Y` [cd/m²] を求め、RevC の4つの高度帯で平均して LED の駆動値にします。

```text
Scene（大気の中身）＋ Numerics（数値の細かさ）
   └─ solver.render ── 分光放射輝度 L(λ)
        └─ color ─────── XYZ・xy・輝度、4高度帯の平均
             └─ led ──── ESP32 用 PWM デューティ表（Cヘッダ）
```

角度はすべて幾何学的な角度（度）です。

| 記号 | 意味 |
|---|---|
| 伏角 d | 太陽中心が地平線の下にある角度。正なら地平線の下（夕方は増え、朝は減る） |
| 高度 h | 見る方向の地平線からの角度（0〜90°） |
| 方位 | 太陽からの相対方位。0°が太陽側、180°が反対側 |

大気は時間変化しないと仮定するので、同じ伏角なら朝と夕で同じ結果です。

## 物理モデル

| 項目 | 扱い | 根拠・制約 |
|---|---|---|
| 幾何 | 半径6371 kmの球面、上端100 km。太陽面を含む2次元の大気（地球の影を含む） | 水平方向の温度・粒子分布は一様 |
| 気体 | US Standard Atmosphere 1976 の温度・気圧 | 観測日の気象ではない |
| 分子散乱 | Rayleigh散乱 | SASKTRAN2 の実装 |
| オゾン | FASCODE標準の鉛直形状を300 DUに規格化、DBM吸収断面積 | Chappuis帯の吸収が薄明の天頂の青さを生む（Hulburt 1953） |
| 対流圏エアロゾル | 対数正規粒径分布（中央値半径100 nm、幾何標準偏差1.6）、屈折率 1.45−0.005i のMie散乱。指数関数の鉛直分布（スケール高度1.5 km）、量は550 nmの乾燥AODで指定 | 球形・単一モード |
| 吸湿成長 | `GF³ = 1 + κ RH/(1−RH)` で粒径を拡大、体積比で水と屈折率を混合、粒子数を保つ | Petters & Kreidenweis (2007)。Kelvin項・履歴は省略。RH ≤ 70%（これより湿ると16 GB で収束を確かめられない。[精度検証.md](精度検証.md)） |
| 成層圏エアロゾル | 硫酸液滴（屈折率 1.43−10⁻⁸i）の対数正規粒径分布。既定は中央値半径80 nm・幾何標準偏差1.6・AOD 0.005、中心20 km・幅4 kmのガウス分布。量・粒径・高さを `Scene` で変えられる | 既定値は平常時の観測（Ugolnikov & Maslov 2017：中央値半径約0.08 µm、幅1.5〜1.6）。薄明の**紫光**を生む（下記）。収束を確かめた範囲は [精度検証.md](精度検証.md) |
| 霧 | **扱わない**（0.5 で削除） | 水滴の鋭い前方散乱は16 GB のメモリで収束しない（[精度検証.md](精度検証.md)） |
| 地表 | Lambert反射、反射率0.1 | 波長によらない |
| 太陽光 | TSIS-1 HSRS 太陽スペクトル、1 AU | 太陽円盤そのもの（直達光）は空の輝度に含めない |
| 屈折 | **既定では入れない**（`solar_refraction=False`） | SASKTRAN2 は太陽光の経路を曲げるが、屈折による光束の広がり（減光）を入れないため、薄明の空を約2倍明るく見積もる。屈折なしの方が実測照度と一致する（[精度検証.md](精度検証.md)）。視線と散乱光の屈折は Geometry2D が未対応 |
| 偏光 | スカラー計算に、粗い格子で求めた「偏光あり−なし」の差を加える（既定）。`num_stokes=3` で I/Q/U を直接解くこともできる | 偏光を無視すると薄明の輝度が最大13%、色度が0.015ずれる |
| 波長 | 380〜780 nm、既定10 nm幅 | 太陽スペクトルは区間平均、等色関数は区間積分 |

## 紫光（薄明の紫の光）

晴れた日の日没後（朝は日の出前）、太陽が地平線の下3〜6°ほどにあるとき、太陽側の空の中ほどが淡い紫に色づくことがあります。これが紫光です。

**しくみ**：このとき地上付近はもう地球の影の中ですが、高度20 km 付近の成層圏はまだ太陽光に照らされています。その太陽光は低い大気を長く通ってきたので赤くなっています。成層圏の微粒子がこの赤い光を観測者の方へ前方散乱し、手前の空気が散乱する青い光と混ざって紫に見えます。Lee & Hernández-Andrés (2003) は、平常時の成層圏の微粒子だけでは赤みが足りず、対流圏と成層圏の両方の散乱・減衰が必要だと結論しています。このモデルは両方を同じ放射伝達計算の中で扱います。火山の大噴火で成層圏の微粒子が増えると、薄明の色は大きく変わります。1883年のクラカタウ噴火の後には、この色の変化が「火山の紫光」と呼ばれました（Ugolnikov & Maslov 2017 の序論）。

**パラメーター**（`Scene` の項目）：

| 項目 | 既定（平常時） | 紫光への効き方 |
|---|---|---|
| `stratospheric_aod550` | 0.005 | 紫光の元。0 にすると紫光は出ません。増やすと紫光が強くなり、太陽側の低い空も橙〜赤に輝きます。紫はその上に出て、太陽が沈むにつれて下がってきます。上限0.02（収束を確かめた範囲） |
| `stratospheric_median_radius_nm` | 80 nm | 粒が大きいほど前方散乱が強くなり、太陽側に集まった鮮やかな紫になります。噴火後は粒が成長します（ピナトゥボ噴火後は有効半径0.6〜0.8 µm まで成長、Russell et al. 1996）。モデルでは40〜150 nm（収束を確かめた範囲） |
| `stratospheric_mode_width` | 1.6 | 粒径の広がり（対数正規分布の幾何標準偏差）。1.2〜1.6 |
| `stratospheric_center_m` / `stratospheric_width_m` | 20 km / 4 km | 層の高さと厚さ。層が高いほど深い伏角まで照らされます。厚さは数値の高度格子（成層圏で2 km）以上が必要です |
| `aod550`（対流圏の塵） | 0.10 | 塵が多いと、成層圏を照らす光も観測者に届く光も弱まり、紫光は薄れます |

**紫の度合い**：`purple_index(XYZ)` は、線形 sRGB（D65 白色）で緑が最も弱いときだけ正になる量 `(min(R, B) − G) / max(R, G, B)` です。青空（R < G < B）や橙の空（B < G）では0、紫〜赤紫（G < R, B）で正になり、明るさにはよりません。`bands.csv` の `purple` 列に4高度帯ごとの値が入ります。LED の既定原色（sRGB）と同じ基準なので、値が正なら LED でも紫に光ります。

**計算結果**（`final` 設定、太陽側の4高度帯の紫の度合い。`results/standard`・`results/eruption` の `bands.csv`）

| 伏角 | standard（平常時） | eruption（噴火後） |
|---|---|---|
| 3° | 出ない | 35〜60°：0.08 |
| 3.5° | 出ない | 35〜60°：0.12 |
| 4° | 15〜35°：0.02 | 35〜60°：0.15 |
| 4.5° | 15〜35°：0.03 | 35〜60°：0.19 |
| 5° | 出ない | 15〜35°：0.03、35〜60°：0.02 |
| 5.5° | 出ない | 15〜35°：0.18 |
| 6〜7° | 6.5°の5〜15°：0.05 | 15〜35°：0.02〜0.04 |

- 紫の出る帯と伏角は、方向の数（入射・出射）を増やしても変わりません。強い紫の度合いの差は0.01程度です。ただし0.03〜0.05の弱い紫は4割ほど変わりえます。また帯の明るさは、伏角3〜4°で3〜4%、伏角5°より深いと5〜9%の差があり、基準（3%）を超えます（[精度検証.md](精度検証.md)）。
- 紫は太陽側にだけ出て、太陽が沈むにつれて高い帯から低い帯へ下がってきます。`eruption` では、その下の帯（15〜35°）が伏角3〜4.5°で橙〜赤に輝きます。
- 成層圏の微粒子を0にすると紫光は出ません。比較ページの48条件（`compare` 設定）で、太陽側・伏角3〜6°・高度15〜60°の帯の紫の度合いの最大値を比べると次のとおりです（4ページの範囲）。

  | 対流圏の塵（AOD） | 成層圏なし | 平常（0.005・80 nm） | 噴火後（0.02・150 nm） |
  |---|---|---|---|
  | 0 | 0 | 0.16 | 0.26 |
  | 0.03 | 0 | 0.08〜0.10 | 0.26〜0.28 |
  | 0.10 | 0 | 0.03〜0.07 | 0.17〜0.24 |
  | 0.30 | 0 | 0.04〜0.09 | 0.16〜0.20 |

  塵が多いほど紫光は薄れます。ただし紫の度合いが正になるのは紫光だけではありません。

  - 塵が0.30と多いと、太陽側の地平線近く（高度0〜15°）が赤紫がかります。成層圏なしでは伏角0.5〜2.5°で0.13〜0.16です。成層圏が平常だと伏角6°まで続き、伏角5〜6°で最大0.10〜0.23と、紫光の範囲の平常の値より大きくなることがあります（比較ページの都会の初期表示はこの条件です）。成層圏が噴火後のときはほとんど出ません（伏角6°の田舎で0.05）。伏角5〜6°は、数値設定による差が基準（輝度3%・色度0.003）を超える範囲です（[精度検証.md](精度検証.md)）。
  - 日没前（伏角0°未満）にも0.07以下のわずかな値が出ます。

  紫光かどうかは、太陽側・伏角3〜6°・高度15〜60°で見てください。
- LED 表（既定の sRGB 原色・指数0.5）でも、同じ伏角・同じ帯で緑のデューティが最も小さくなり、紫に光ります。例：`eruption` の伏角4°、35〜60°帯で R・G・B = 0.044・0.033・0.039。
- 伏角4°ごろの紫光の明るさは、35〜60°帯で約20 cd/m²（standard 17、eruption 23）です。
- 反対側の低い空（高度15°以下）に伏角1〜2°で出るピンク〜紫は、地球の影の上に出るビーナスベルトです。紫光とは別の現象です。

## 数値解法

SASKTRAN2 の Geometry2D（球面・2次元）逐次散乱法（successive orders）を使います。放射輝度を成分に分けて、それぞれに合った格子で計算します。

```text
L = L_1回散乱（細かい高度格子）
  + L_多重散乱（散乱源の格子で解いた場 − 同じ格子での1回散乱）
  + ΔL_偏光（粗い格子での I/Q/U 計算 − スカラー計算）
```

- **1回散乱**は地球の影の境界をまたぐため高度格子に敏感です。0–1 km を25 m、1–10 km を125 m、10–30 km を250 m、30–100 km を500 m 刻みで積分します。
- **多重散乱**は、散乱源の高度を下層から 100/2000/4000/8000 m 刻み、大気の高度格子を 50/500/2000/4000 m 刻み、太陽面内の水平方向を観測者の位置±3°は0.5°刻み（外側は間隔を2倍ずつ広げて±45°まで）で解きます。
- 精度を最も左右するのは**散乱光が入ってくる方向の積分点数**（Lebedev 求積）です。既定（`final`）は入射302方向、散乱源の標本は出射50方向です。深い薄明では入射点数を増やすほど結果が変わるため、ここに計算資源を集中させています（[精度検証.md](精度検証.md)）。
- **スカラー計算**では、前方に鋭い散乱を整合的な Delta-M 打切り（Wiscombe 1977。次数16）で扱い、1回散乱は完全な位相関数で TMS 補正（Nakajima & Tanaka 1988）します。
- **偏光補正**は、太陽光の1回散乱はスカラーで厳密なので多重散乱にだけ効きます。同じ粗い格子でベクトルとスカラーを解き、その差を加えます（格子の誤差が打ち消し合う）。
- メモリを抑えるため、伏角をいくつかのグループに分けて多重散乱を解きます（約10 GB 以内）。

数値設定は `Numerics` にまとまっています。

| プリセット | 用途 | 入射/出射方向 | 波長幅 | 目安の時間 |
|---|---|---|---|---|
| `preview` | 動作確認 | 110 / 26 | 20 nm | 数十秒 |
| `compare` | 比較ページ（48条件、重複を除くと39条件） | 302 / 50 | 20 nm | 1条件約3.5分、全体で約2時間20分 |
| `final` | LED 表・精度検証（既定） | 302 / 50 | 10 nm | 晴天で約7分 |

## 色と輝度

CIE 1931 2°等色関数で

```text
X = 683 Σ L(λᵢ) ∫ x̄ dλ,  Y = 683 Σ L(λᵢ) ∫ ȳ dλ [cd/m²],  Z = 683 Σ L(λᵢ) ∫ z̄ dλ
x = X/(X+Y+Z),  y = Y/(X+Y+Z)
```

RevCの4高度帯（0–5°、5–15°、15–35°、35–60°）の値は、XYZ を `cos h` で重み付けした立体角平均です。RGBではなく光の量（XYZ）で平均します。

## LED への変換（`akutou-sky led`）

1. 指定方位（既定は太陽側）の4高度帯の XYZ を伏角ごとに求める
2. 輝度を圧縮：`Y_LED = (Y / Y_ref)^p`（既定 p = 0.5、`Y_ref` は表中で最も明るい帯）。実際の薄明は約6桁明るさが変わり、ドームのLEDでそのまま出すことはできないため。p = 1 なら比例
3. 色度 xy は保ったまま、LED原色の3×3行列で R・G・B のデューティを解く
4. LEDで出せない鮮やかな色は、同じ輝度のまま LED の白の方向へ彩度を落とす
5. PWM のデューティは光量に比例するので、ガンマ補正はしない。12 bit の1段（1/4095）未満は0

LED原色は既定では sRGB の値です。分光放射計などで各チャネルの xy と最大輝度を測ったら、[led_primaries.example.json](../led_primaries.example.json) の形式で `--primaries` に渡してください。帯ごとに違う LED なら `"bands": [...]` に4組書けます。ドームの反射や配光の重なりは含まれないので、最終的には実機で見え方を確認して `--exponent` を調整します。

## 含まないもの

霧（地表付近の水滴）、太陽円盤の直達光、夜光・星・月・街明かり（伏角12°付近から先は背景光が無視できなくなる）、雲、地形、水平方向の大気のむら、視線と散乱光の屈折、可視域の O₂・H₂O・NO₂ の細い吸収帯、暗所での人間の色覚の変化。
